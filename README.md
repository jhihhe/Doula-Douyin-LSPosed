# Doula

### 把抖音，调成你的习惯。

更专注的浏览，更顺手的操作。

**作者：`@JhihHe`**

抖音 40.6.0 · LSPosed API 102 · Android 13+ · ARM64

[功能介绍](#功能介绍) · [使用方式](#使用方式) · [反馈问题](https://github.com/jhihhe/Doula/issues)

</div>

---

Doula 是独立的抖音增强模块，将浏览、播放、消息与媒体选项集中到简洁的设置页面。界面采用清晰分组、红色强调色与深浅色适配，去除装饰性 emoji，保留原有功能设置。

## 功能介绍

| 方向 | 可配置选项 |
| --- | --- |
| 浏览与过滤 | 视频过滤、文案过滤、顶部与底部菜单、视频控件 |
| 播放与手势 | 播放行为、透明度、系统栏、手势、定时退出 |
| 消息体验 | 防撤回、已读状态、输入状态等设置 |
| 媒体工具 | 视频、图文、评论、表情、语音相关分享与保存入口 |

以上为模块提供的设置范围。当前适配测试版已完成本地构建与静态检查，尚未完成真机逐项验证；保留开关不代表全部功能已在新版生效。

## 使用方式

1. 准备 Android 13 或更新版本的 ARM64 设备，以及支持现代 Xposed API 102 的 LSPosed 框架。
2. 安装 Doula，包名为 `io.github.jhihhe.doula`。
3. 在 LSPosed 中启用模块，并将作用域设为抖音 `com.ss.android.ugc.aweme`。
4. 完全停止并重新启动抖音 40.6.0。
5. 通过抖音内的模块入口打开 Doula 设置。桌面 Doula 图标可查看模块说明与本宣传页。

新包名与旧模块不同。请避免同时启用旧内置模块和 Doula，以免重复 Hook。
