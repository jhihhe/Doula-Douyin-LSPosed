Doula 是用于抖音的独立增强模块，围绕界面净化、视频与文案过滤、播放控制、分区手势、消息与评论、媒体保存提供集中设置。模块保留原“抖+”的功能代码与配置入口，并为抖音 40.6.0 添加现代 LSPosed API 102 兼容层。

Doula is an Android Douyin enhancement module for LSPosed / Xposed, with feed filtering, UI customization, gesture shortcuts, playback controls, messaging options, and media tools. This repository contains promotional documentation only; module source code is not published here.

**当前为适配测试版。下列内容是依据模块配置、界面与代码整理的完整功能说明，并非“全部功能已在新版实测有效”的承诺。** 新包已通过构建、签名与安装检查；抖音内实际加载、界面与功能仍需逐项验证。暂不提供公开下载文件。

## 完整功能

### 1. 首页、菜单与控件净化

| 功能 | 选项与细节 |
| --- | --- |
| 顶部菜单隐藏 | 从目标应用收集顶部标签，勾选要隐藏的项目并保存。初始隐藏词为热点、中视频、同城、直播、经验、关注、团购、朋友、商城。实际可选项随目标界面变化。**不要全选顶部标签，原模块明确提示可能导致闪退。** |
| 底部菜单隐藏 | 从目标应用收集底部标签，选择要隐藏的项目。初始隐藏词为经验、探索、商城、拍摄。 |
| 视频控件隐藏 | 选择主页视频控件；支持全选与全不选。列表包含反馈图标（仅测试版）、画圈搜索、弹幕按钮、弹幕，以及从目标应用读取的 Flux 控件标识。初始隐藏标识为 `digg`、`collect`，对应点赞、收藏相关控件。 |
| 分享弹窗净化 | 按项目隐藏抖音分享面板中的按钮；下方列出全部 18 个项目。初始不隐藏。 |
| 关注确认 | 代码中保留关注确认弹窗，文案为“确定要关注该用户吗？”，提供关注与取消操作；它不是独立的设置开关，是否出现取决于对应 Hook。 |
| 双列页面相关适配 | 保留双列内容处理与动画相关 Hook；40.6.0 做了类型迁移。该部分属于底层兼容处理，没有新增的独立“双列模式”开关。 |

分享弹窗可隐藏的完整清单：**推荐、转发到日常、私信、建群分享、帮上热门、分享链接、身边的人、不感兴趣、保存至相册、合拍、一起看视频、生成图片、桌面刷抖音、举报、动态壁纸、赞赏视频、播放反馈、本地推**。部分项目只有满足抖音对应场景条件才会出现。

### 2. 视频类型与文案过滤

类型过滤支持以下 **11 类**：

| 类型 | 用途 |
| --- | --- |
| 直播 | 过滤按原模块规则识别的直播内容。 |
| 图文 | 过滤图文内容。 |
| 广告 | 过滤按内容字段识别的广告。 |
| 长视频 | 过滤原模块长视频规则匹配的内容；不要把它与下方“视频时长提醒”的设置混为同一个开关。 |
| 推荐卡片 | 过滤推荐卡片。 |
| 推荐商家 | 过滤推荐商家内容。 |
| 空文案 | 过滤没有文案的内容。 |
| AI互动 | 过滤 AI 互动类内容。 |
| 音乐 | 过滤音乐类内容。 |
| 全景视频 | 过滤全景视频。 |
| 购物 | 过滤购物类内容。 |

初始选中 **广告、推荐卡片、推荐商家、AI互动、音乐**。可以按自己的习惯重新选择并保存。类别名称对应原模块判定规则，不代表能够识别或屏蔽所有同类内容。

**文案过滤**在输入框中配置，一行一条规则，点击保存。代码按正则表达式匹配内容文案，并把可读取的内容风险提示文字一起纳入匹配；采用 `find()`，不要求整段文本完全一致。普通文字也可以作为规则，含 `.`、`*`、`[` 等正则符号时应注意其含义。初始规则为空。

视频过滤代码保留对多个内容列表入口的处理；推荐流、图文或双列等场景是否全部生效仍需实际版本验证。它不修改已经发布的作品。

### 3. 播放、提醒与刷新

| 功能 | 使用方式与细节 |
| --- | --- |
| 自动连播 | 提供自动连播开关，初始关闭；通过对应播放能力 Hook 启用。 |
| 播放完成后自动暂停 | 独立开关，初始关闭；与自动连播分开配置。两者同时开启时的最终行为需真机确认。 |
| 定时退出 | 输入分钟数，在键盘“完成”后保存。初始为 0，即不启用定时退出。退出提示提供“忽略本次”和“立即退出”。空值、非正数或无效数字按原逻辑保存为 0。 |
| 视频时长提醒 | 输入分钟数，在键盘“完成”后保存。初始阈值 10 分钟；超过阈值的当前视频显示时长提醒。这里是提醒阈值，不能直接解释成“长视频过滤阈值”。 |
| 首页刷新确认 | 为主页点击刷新增加确认弹窗，提供取消与刷新，初始关闭。 |
| 发布时间与发布地 | 可分别选择“显示时间”“显示发布地”“多彩显示”。初始未选中；目标内容没有发布地时不会凭空生成。 |

### 4. 四区域手势快捷操作

视频触控区域划分为 **左上、右上、左下、右下**。每个区域分别设置 **双击** 和 **长按**，共八个动作位置；修改后保存在对应的手势配置中。

| 手势 | 全部可选动作 | 初始动作 |
| --- | --- | --- |
| 双击 | 忽略、点赞、打开分享、打开评论、打开视频信息、打开 Doula 设置、拍摄、收藏 | 四个区域均为打开视频信息。 |
| 长按 | 默认、忽略、打开视频信息、打开 Doula 设置、拍摄、收藏、打开分享、打开评论 | 四个区域均为默认，调用原有长按处理。 |

“忽略”表示不执行该手势动作；“默认”是保留抖音原处理。动作能否执行还取决于当前内容与页面是否具备对应能力。模块另保留内部 `doubleTapType` 字段，默认值为 0；当前未找到独立 UI 入口与业务读取，因此不把它宣传为额外可用的手势模式。

### 9. 骰子、猜拳与辅助操作

- **摇骰子**：原表情操作保留点数选择，提供 1–6、随机、取消与发送操作。
- **猜拳**：保留石头、剪刀、布选择，以及随机、取消与发送操作；未选择时提示先选择手势。选择 UI 使用几何符号，业务功能保留。
- **调试模式**：保留长按切换入口与开启/关闭提示，初始关闭；日志用于兼容问题排查，入口是否出现需实际加载后确认。
- **重新适配**：保留确认后重新适配并重启抖音的辅助操作。该操作用于原模块匹配流程，不等于可以自动适配任意抖音版本。
- **个人主页空作品任务引导相关 Hook**：原实验类在 40.6.0 中已消失，目前未完成迁移。列出此项用于说明保留代码的范围，不作为当前可用卖点。

## 安装使用

| 项目 | 要求 |
| --- | --- |
| Android | Android 13 或更新版本，ARM64 |
| 框架 | 支持现代 Xposed API 102 的 LSPosed 实现 |
| 目标应用 | 抖音 `com.ss.android.ugc.aweme` |
| 目标版本 | 40.6.0，versionCode 400601 |
| 模块名称与包名 | Doula / `io.github.jhihhe.doula` |
| 模块作者 | `@JhihHe` |
| 当前构建 | `40.6.0-api102-preview.4`，适配测试版 |

1. 安装 Doula。在 LSPosed 中启用模块，并将作用域设置为上述抖音包。
2. 避免同时启用旧内置模块与 Doula，防止重复 Hook；新包名不会覆盖旧 `com.android.admin` 模块。
3. 完全停止并重新启动抖音。
4. 在原模块工具区或侧边栏入口打开 Doula 设置。可以通过四区域手势把常用动作设为打开设置。
5. 桌面 Doula 图标打开独立说明页。设置页、关于页和独立页均链接到本仓库。
6. 按需修改配置。选择列表点击保存；分钟数与日期格式输入按键盘“完成”保存。需要确认 Hook 的选项，应结合 LSPosed 日志检查。

当前没有验证抖音极速版、火山版、国际版 TikTok 或其他抖音版本。历史代码包含其他包名，不能据此宣传这些应用已经适配。
